# PGR107 – Python Programming

Eksamensbesvarelse i **PGR107 Python Programming** ved Høyskolen Kristiania, våren 2026.

Besvarelsen er levert som en Jupyter Notebook (`.ipynb`) og inneholder kode, dokumentasjon, testing, visualiseringer og refleksjoner rundt løsningene.


## Innhold

Eksamen besto av flere Python-oppgaver med fokus på blant annet:

- Python-programmering og kontrollflyt
- Lister, slicing og funksjoner
- Debugging og feilretting
- Dictionaries og datastrukturer
- Koordinater og avstandsberegning
- NumPy
- Pandas
- Databehandling av CSV-filer
- Datavisualisering med Matplotlib
- Analyse og sammenligning av datasett

## Oppgaver

### Task 1 Supernacci
Implementasjon av en funksjon for beregning av fiktive Supernacci-tall ved bruk av lister, slicing og `sum()` uten rekursjon.

### Task 2 4-sided dice
Feilretting og forbedring av et eksisterende Python-program for et enkelt terningspill.

### Task 3 Cities and Points of Interest
Arbeid med dictionaries, koordinater og avstandsberegning. Oppgaven omfattet blant annet:

- Finne nærmeste by og interessepunkt (POI)
- Beregne geografiske grenser for byer
- Tilordne POI-er til byer
- Beregne gjennomsnittlig vurdering
- Sortere POI-er etter avstand

### Task 4 NumPy
Implementasjon av en egen `trace()`-funksjon for todimensjonale NumPy-arrays.

### Task 5 Data analysis
Analyse av karakterdata fra norske videregående skoler ved bruk av Pandas og Matplotlib.

Arbeidet omfattet behandling og visualisering av karakterdata, samt sammenligning mellom standpunkt, skriftlig eksamen og muntlig eksamen. I den avsluttende analysen ble data fra Oslo sammenlignet med Troms.
